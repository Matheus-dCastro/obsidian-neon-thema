# Change Log

All notable changes to the "obsidian-neon" extension will be documented in this file.

## [1.4.0]

### Added
- **Maple Mono & Maple Mono NF Font Support**: Added commands to install and activate Maple Mono and Maple Mono NF fonts directly from VS Code (with automatic preference for NF on Ubuntu/Linux).
- **Font Ligatures & Highlighting ("higthline")**: Native ligature enablement, cursor smooth caret animation, expanded blinking, and line highlight customization.
- **Terminal Autocomplete**: Activated suggestions and autocomplete provider integration for the integrated terminal.
- **Python Vibrant Pink Syntax**: Aligned Python control flow, imports, and keywords with the signature Dracula hot pink (`#FF79C6`) across themes, keeping Dracula Syntax intact.

## [1.2.0]

### Added
- **Obsidian Neon (Dracula Syntax)**: Added version 3 theme variant that integrates the workbench, window, and icon colors of the default Obsidian Neon with the syntax highlighting and letter colors of the Dracula edition.

## [1.1.0]

### Added
- **Dual Theme Support**: Package now distributes both **Obsidian Neon** and **Obsidian Neon (Dracula)** variants.
- **Ghost Letters & Italic Syntax**: Enhanced cursive/italic styling for comments, docstrings, keywords, storage types, and Python control flow.
- **Full Semantic Token Colors**: Native semantic highlighting for functions (bold neon green), keywords (italic hot pink), parameters, variables, and constants.
- **Glowing UI Enhancements**: Custom cursor glow, inlay hint coloring, and ghost text support.

## [1.0.0]

- Initial release of Obsidian Neon theme.
